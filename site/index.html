How points work

Ranked by a rolling 7- or 14-day window, not career total and not UTC midnight. Shipping, reviewing, and finding bugs are different jobs — they share one overall score, and each has its own board. Open any person to see the ledger.

Typical merged PR 10–14 pts base 10 + size bonus up to 4 (a small input, not the definition of value). High-impact labels ×1.5 · bug-fix +4
Same-day extra PRs diminishing, no cap 1=100%, 2=100%, 3=80%, 4=65%, 5=50%, 6+=35%. Rolling 24 hours, not a UTC-day reset.
Substantive review 4–8 pts outcome (comment / approve / request-changes) · +3 for inline comments · +4 if requested changes later merge. Authors are not penalized for lack of review.
Issue filed / closed +5 / +3 unlabeled bug +8. A difficulty: 1…6 label replaces the flat file points (3–36). Finding a real bug can beat a tiny PR.

Worked example: two PRs in 24h both score in full. A third is worth 80%, a sixth+ still 35% — never zero. A 71-PR burst is still a burst (most of those PRs sit on the 35% floor), but a 7-PR day is worth more than a 2-PR day. First contribution is a badge, not a point multiplier.

Pull requests

Counts = every merged PR you authored, any branch. Points only for merges into main or master. Lockfiles / generated / vendored paths are subtracted from size. Docs-only PRs are classified separately (not a flat +25%). 24h diminishing: 1=100%, 2=100%, 3=80%, 4=65%, 5=50%, 6+=35%.

Reviews

Counts = unique PRs you reviewed (submitted review or inline comments), including open and unmerged PRs. Points follow outcome, plus bonuses for inline comments, reviewing a nontrivial PR, and requested changes that later merge. A short review that names a real defect still scores; a padded LGTM does not. No self-reviews. Best review per PR. Bots never appear.

Issues

Counts = issues you opened (including duplicates). Close bonus (+3) goes to the person who closed it. +5 to open a valid issue, +8 if labeled bug. Rejected as duplicate, wontfix, invalid / not-planned score nothing. Apply difficulty: 1…6 when the bug actually mattered — that is the intended quality signal.

Humans only

Dependabot, GitHub Actions, Renovate, [bot] accounts, and named agents (MantisCartography, Codex, Copilot) are excluded. Rankings track who’s actively shipping now. First PR / first review / first bug report are badges, not extra points.
