How points work

Ranked by the selected window (past 7 or 14 days), not career total. A day of shipping and a day of reviewing are in the same band. Merging 70 times in one day is still one day.

Typical merged PR 10–22 pts base 10 + size bonus up to 12 (flattens after ~60 lines) · unreviewed ×0.5
A day of shipping cap 36 pts ~2 solid PRs. Extra merges the same day add nothing once the cap is hit
Substantive review 6–10 pts comment / approve / request-changes · one per PR · cap 20 pts/day
Issue filed / closed +2 / +1 max 6 issue pts / day

Worked example: two reviewed PRs in a day ≈ 36 pts (the daily cap). Seventy-one unreviewed merges that same day still ≈ 36 pts — not 190. Coding five days that way beats one dump. A review (8–10) is part of a day, not a substitute for a week of shipping.

Pull requests

Counts = every merged PR you authored, any branch. Points only for merges into main or master. Lockfiles / generated / vendored paths are subtracted from size using per-file line counts. After 2 merges/day, further PRs decay toward zero. Hard cap 36 PR pts/day.

Reviews

Counts = unique PRs you reviewed (submitted review or inline comments), including open and unmerged PRs. Points: Commented (+6, ≥40 chars), Approved (+8), or Changes requested (+10, ≥20 chars). Inline comments add to body length. No self-reviews. Best review per PR (not the first click). Cap 20 pts/day. Bots never appear.

Issues

Counts = issues you opened (including duplicates). Close bonus (+1) goes to the person who closed it. +2 to open a valid issue. Rejected as duplicate, wontfix, invalid / not-planned score nothing. Burst decay after 2/day. Hard cap 6 issue pts/day.

Humans only

Dependabot, GitHub Actions, Renovate, [bot] accounts, and named agents (MantisCartography, Codex, Copilot) are excluded. Rankings track who’s actively shipping now.

Ranked by points in the selected window only — not lifetime totals.
PR / review / issue columns are raw activity counts (no daily cap). Points still cap and decay.
Why a score looks “small”: same-day PR floods are discounted; issues hard-capped. Hover a total to see the split.
